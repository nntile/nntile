# GPT-2 Model Tests

Tests for the NNTile C++ GPT-2 graph model components. Reference data is stored in safetensors (no Python wrappers at test runtime).

## Layout

Tensors use **(batch, seq, hidden_size)** in graph unless noted. Embeddings take `input_ids` with shape `(batch, seq)`. `Gpt2Causal` outputs logits `(batch, seq, vocab_size)`.

## Test Coverage

Shared building blocks used by GPT-2 (not covered only inside model tests):

- **layer_norm** (NN op): `nntile/tests/nn_graph/ops/layer_norm.cc` — structure, autograd, PyTorch forward/backward
- **LayerNorm** (module): `nntile/tests/module/layer_norm.cc` — parameters, forward graph, PyTorch forward/backward

- **gpt2_config**: `Gpt2Config` validation and defaults
- **gpt2_mlp**: `Gpt2MLP` forward, roundtrip, PyTorch forward/backward
- **gpt2_attention**: `Gpt2Attention` forward, roundtrip, PyTorch forward/backward (`[nomask]` bidirectional SDPA, `[causal_mask]` causal)
- **gpt2_block**: `Gpt2Block` forward, roundtrip, PyTorch forward
- **gpt2_model**: `Gpt2Model` forward, roundtrip, PyTorch forward
- **gpt2_causal**: `Gpt2Causal` forward, roundtrip, PyTorch forward


### Attention masks

- **`[nomask]`** — graph passes `mask=nullptr` (full attention). PyTorch refs use
  HuggingFace `eager_attention_forward` with causal masking disabled (not
  `GPT2Attention.forward` with `attention_mask=None`, which still applies a
  built-in causal mask in eager mode).
- **`[causal_mask]`** — BOOL causal mask in safetensors; refs use HF with additive mask.

## Test Data (Safetensors)

Generated by `generate_test_data.py` in this directory (CTest fixtures). Uses PyTorch and HuggingFace `transformers` (`modeling_gpt2`).

```bash
python nntile/tests/model/gpt2/generate_test_data.py --block mlp --output /tmp/gpt2_data --seed 42
python nntile/tests/model/gpt2/generate_test_data.py --block attention --output /tmp/gpt2_data --seed 42
python nntile/tests/model/gpt2/generate_test_data.py --block attention_causal --output /tmp/gpt2_data --seed 42
python nntile/tests/model/gpt2/generate_test_data.py --block block --output /tmp/gpt2_data --seed 42
python nntile/tests/model/gpt2/generate_test_data.py --block model --output /tmp/gpt2_data --seed 42
python nntile/tests/model/gpt2/generate_test_data.py --block causal --output /tmp/gpt2_data --seed 42
```

Each block writes `gpt2_<block>.json` and `gpt2_<block>.safetensors`.

## Save/Load

GPT-2 modules use `Module::save()` / `Module::load()` with qualified parameter names (e.g. `model.transformer.wte.vocab`, `block.attn.q_weight`).

## Running Tests

```bash
ctest -R 'tests_graph_model_gpt2'
```
