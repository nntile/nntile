# GPT-Neo Model Tests

Tests for the NNTile C++ GPT-Neo graph model components. Reference data is stored in safetensors (no Python wrappers at test runtime).

## Naming

Same convention as GPT-2 and Llama: types `Gptneo*` (e.g. `GptneoModel`), directory `gptneo/`, namespace `nntile::model::gptneo`. Human-readable docs may say "GPT-Neo".

## Layout

Tensors use **(batch, seq, hidden_size)** in C-order unless noted. Embeddings take `input_ids` and `position_ids` with shape `(batch, seq)`. `GptneoCausal` outputs logits `(batch, seq, vocab_size)`.

## Test Coverage

Shared building blocks used by GPT-Neo (not covered only inside model tests):

- **layer_norm** (module): `nntile/tests/module/layer_norm.cc`
- **gelutanh** (NN op): used by `GptneoMLP`

- **gptneo_config**: `GptneoConfig` validation, `attention_layers` / HF `attention_types` JSON parsing
- **gptneo_mlp**: `GptneoMLP` forward, roundtrip, PyTorch forward/backward (HF `nn.Linear` weights transposed in fixtures; GPT-2 uses `Conv1D` without `.T`)
- **gptneo_attention**: forward, roundtrip, PyTorch forward/backward (`[nomask]`, `[causal]`, `[local]`)
- **gptneo_decoder**: `GptneoDecoder` forward, roundtrip, PyTorch forward/backward
- **gptneo_model**: `GptneoModel` forward, roundtrip, PyTorch forward/backward
- **gptneo_causal**: `GptneoCausal` forward, roundtrip, PyTorch forward/backward

### Attention masks

- **`[nomask]`** — `mask=nullptr` (full bidirectional SDPA in the graph).
- **`[causal]`** — BOOL causal mask (`sdpa_causal_mask_bool_fortran_fill`).
- **`[local]`** — BOOL sliding-window mask for layer_id=1 (`sdpa_gptneo_local_mask_bool_fortran_fill`).

Production models alternate global (even layers) and local (odd layers) attention; training and generation pass both `attn_mask` and `attn_mask_local`.

## Test Data (Safetensors)

Generated by `generate_test_data.py` in this directory (CTest fixtures). Uses HuggingFace
`transformers` (`modeling_gpt_neo`) for weights and forward/backward references; attention
uses HF Q/K/V/O projections with `scaled_dot_product_attention` to match graph
`sdpa_eager` (not HF eager `_attn`). MLP uses `GPTNeoMLP.forward` with biases zeroed.

```bash
python nntile/tests/model/gptneo/generate_test_data.py --block mlp --output /tmp/gptneo_data --seed 42
python nntile/tests/model/gptneo/generate_test_data.py --block attention --output /tmp/gptneo_data --seed 42
python nntile/tests/model/gptneo/generate_test_data.py --block attention_causal --output /tmp/gptneo_data --seed 42
python nntile/tests/model/gptneo/generate_test_data.py --block attention_local --output /tmp/gptneo_data --seed 42
python nntile/tests/model/gptneo/generate_test_data.py --block decoder --output /tmp/gptneo_data --seed 42
python nntile/tests/model/gptneo/generate_test_data.py --block model --output /tmp/gptneo_data --seed 42
python nntile/tests/model/gptneo/generate_test_data.py --block causal --output /tmp/gptneo_data --seed 42
```

Each block writes `gptneo_<block>.json` and `gptneo_<block>.safetensors`.

## Save/Load

GPT-Neo modules use `Module::save()` / `Module::load()` with qualified parameter names (e.g. `model.wte.vocab`, `model.layers_0.self_attn.q_weight`).

## Running Tests

```bash
ctest -R 'tests_graph_model_gptneo'
```

Set `GPTNEO_DATA_DIR` to the directory containing generated fixtures when running binaries outside CTest.
