# T5 graph model tests

Reference data is generated by `generate_test_data.py` (Hugging Face
Transformers forward/backward; NNTile-layout weights). CTest fixtures run the
script before data-driven tests.

## Manual data generation

```bash
python nntile/tests/model/t5/generate_test_data.py --block ff --output /path/to/t5_data --seed 42
```

Blocks: `ff`, `attention`, `attention_causal`, `cross_attention`,
`encoder_block`, `decoder_block`, `model`, `conditional`.

## Run tests

```bash
ctest --test-dir build -R 'tests_graph_model_t5' --output-on-failure
```
